# ConnectExamples

This directory contains a comprehensive example app that utilizes
Connect-Swift and provides the ability to [chat with ELIZA][eliza-demo] over
each supported protocol using either unary or streaming APIs:

- [`ElizaSwiftPackageApp`](./ElizaSwiftPackageApp): Uses
  **Swift Package Manager**.

[eliza-demo]: https://connectrpc.com/demo
